## Enum Architecture Summary

```dart
// user_settings.dart
enum ThemePreference { system, light, dark }

// in UserSettings @collection class:
@Enumerated(EnumType.name)
ThemePreference themePreference = ThemePreference.system;
bool didMigrateThemePreference = false;
```

Persistence: Isar stores `"system"` / `"light"` / `"dark"` as strings
(`EnumType.name`). This matches the existing `PrayerCardDisplayMode`,
`AthkarDisplayMode`, and `AthkarSessionViewMode` pattern in the same file.

app.dart reads:
```dart
final themePreference = settingsState is SettingsLoaded
    ? settingsState.settings.themePreference
    : ThemePreference.system;
// ...
themeMode: switch (themePreference) {
  ThemePreference.light  => ThemeMode.light,
  ThemePreference.dark   => ThemeMode.dark,
  ThemePreference.system => ThemeMode.system,
},
```

## Migration Behavior

`_runThemeMigrationIfNeeded()` runs once on `loadSettings()` cold start.

| Prior state | Migration result |
|-------------|-----------------|
| `isDarkMode = true` | → `themePreference = ThemePreference.dark` |
| `isDarkMode = false` | → `themePreference = ThemePreference.system` |
| New install (no prior record) | → `themePreference = ThemePreference.system` (default) |
| Already migrated | → skipped (`didMigrateThemePreference = true`) |

`isDarkMode` field is preserved in `UserSettings` (not removed). It is
no longer read by `app.dart` or `SettingsState.props`. It will be swept
in PR-CLEANUP.

## UI Behavior Summary

The Dark Mode toggle is replaced by a "Theme" `_NavTile` in the
Appearance section. Tapping opens a bottom-sheet picker with three
radio options, using the same visual pattern as the Language picker.

| User action | Behavior |
|-------------|----------|
| Settings → Appearance → Theme | Opens picker showing: Light / Dark / System Default |
| Selects option | `toggleThemePreference()` called; Isar updated; `SettingsCubit` emits new state; `app.dart` BlocBuilder rebuilds `MaterialApp`; theme switches live |
| Dark system device, System selected | App follows OS — dark |
| Light system device, System selected | App follows OS — light |
| Dark selected | App always dark regardless of OS |
| Light selected | App always light regardless of OS |
| App restarted | Selection survives (persisted in Isar) |
