What changed in PR3 reconciliation
  • Countdown 44pt / weight 300 — was 64pt. 64pt created emotional urgency and pushed habits/tasks below the fold on small phones.
  • Surface uses forest gradient #0F3D2E → #1A5A45 (was indigo→teal). Single static glass overlay — no animated shimmer.
  • Whole card is the only CTA — opens the existing PrayerDetailsPage (Today / Week / Month tabs). No separate "Start dhikr" button. Dhikr surfaces via the existing 40-minute post-prayer window already wired in PrayerCubit.
  • Active prayer state: calm color + label swap, no pulse, no scale, no "ALLAHU AKBAR" overlay. The adhan audio is the moment.
  • Nafl chip surfaces Duha (post-sunrise → pre-Dhuhr) and Qiyam (last third of night). One chip max at a time. Optional, opt-in via existing setting.
  • Progress bar is now directionality-aware (uses flex justify, not scaleX(-1)) so the fill anchors to the trailing edge in RTL correctly.
  • Sunrise / sunset values come from PrayerType.sunrise + PrayerType.maghrib already in PrayerCubit. No new data source.
  • Arabic font: Calibri only. Cairo references in earlier drafts are deprecated.
