### Prayer Architecture Note (CRITICAL)
Prayer toggle hierarchy was recently refactored (Phase 8.1, 2026-05-06):
- `isPrayerEnabled` = master toggle
- `isPrayerCardEnabled` = card visibility sub-toggle (NEW)
- `isPrayerNotificationsEnabled` = scheduling sub-toggle
- `enablePrayerReminders` = 15-min reminder sub-sub-toggle
- `didMigratePrayerFeatureSettings` = one-time migration flag

Any design system spec that treats prayer as a single `modules.prayer` boolean is outdated. The 4-level hierarchy must be preserved.
