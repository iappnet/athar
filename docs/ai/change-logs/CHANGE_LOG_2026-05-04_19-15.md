## 1. ROOT CAUSE (exact)

### Widget Skeleton — ALL three widgets

**Cause A — ISO date parsing failure (Swift, committed files):**
`AtharPrayerWidget.swift` (committed) uses `ISO8601DateFormatter()` which requires a timezone designator. Dart's `DateTime.toIso8601String()` produces `"2026-05-04T15:30:00.000"` (no TZ) → formatter rejects it → `prayerTime = nil` → widget shows "--:--" / placeholder name.

Task and Habit widgets were also on old committed versions (`StaticConfiguration`, no `WidgetLanguage` support).

**Cause B — App Group race condition (Dart, fixed in previous session):**
`HomeWidget.setAppGroupId()` was called after `runApp()`. Global cubits emit first state during `MultiBlocProvider` initialization → `pushTaskData/pushHabitData` called before App Group configured → data lands in default UserDefaults suite, not `group.com.iappsnet.athar`.

**Status of fix:**
- Cause A: **Working-tree Swift files already correct** (epoch ms parsing, `AppIntentTimelineProvider`, `WidgetLanguage` enum). Needs `flutter build ios` + device install.
- Cause B: **Fixed in previous session** (`WidgetDataService.init()` before `runApp()`).

### Task "cannot save"

`showDialog()` for `ConflictDialog` had `barrierDismissible: true` (Flutter default). Tapping outside the dialog → `shouldProceed = null` → `null != true` → function returns early → task NOT saved. User sees no error.

### Habit "cannot save" (no feedback)

`_saveHabit()` checked `titleController.text.isNotEmpty`. When empty: silently returned, `Navigator.pop` was NOT called (sheet stayed open), but NO error message shown → button appeared non-functional.

**`_saveHabit()` — added validation, trimmed title:**
```dart
// BEFORE
void _saveHabit() {
  if (titleController.text.isNotEmpty) {
    int target = ...;
    final cubit = context.read<HabitCubit>();
    // ... save ...
    Navigator.pop(context);
  }
  // SILENT no-op on empty title

// AFTER
void _saveHabit() {
  final trimmedTitle = titleController.text.trim();
  if (trimmedTitle.isEmpty) {
    setState(() => _titleError = 'يرجى إدخال اسم العادة');
    return;  // explicit return, error shown in TextField
  }
  setState(() => _titleError = null);
  int target = ...;
  final cubit = context.read<HabitCubit>();
  // ... save with trimmedTitle ...
  Navigator.pop(context);
}
```

**Before:** Empty title → silent no-op, button looked broken.
**After:** Empty title → red error text under title field "يرجى إدخال اسم العادة". Sheet stays open. Non-empty title → saves and closes.
