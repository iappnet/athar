# Athar — Architecture Index

## Architectural Style

Clean Architecture with feature-based modules. Every feature has:
```
features/<name>/
  data/
    datasources/   # Remote (Supabase) and/or local (Isar)
    models/        # @collection/@embedded Isar models with fromJson/toJson
    repositories/  # Concrete implementations
  domain/
    entities/      # Pure Dart + Equatable
    repositories/  # Abstract interfaces
    usecases/      # Either<Failure, T> — not all features use explicit use cases
  presentation/
    cubit/         # Cubit + State
    pages/         # Full-screen routes
    widgets/       # Feature-local widgets
```

**Exception**: `task` has no local Isar datasource class — Isar is accessed directly from `TaskRepositoryImpl`.

## State Management

**flutter_bloc Cubit** throughout. No Bloc (no events).

### Global cubits (provided in `app.dart` `MultiBlocProvider`):
- `AuthCubit`, `PrayerCubit`, `TaskCubit` (`..watchTasks(DateTime.now())`), `HabitCubit` (`..loadHabits()`), `DhikrCubit`, `FocusCubit`, `HealthCubit`, `StatsCubit`, `SyncCubit`, `SettingsCubit`, `CategoryCubit`, `SubscriptionCubit`, `NotificationsCubit`, `CalendarCubit`, `LocaleCubit`, `CelebrationCubit`, `SpaceCubit`, `AssetsCubit`

### Local cubits (provided at page level — SHADOW global ones):
- `MainPage` provides its own `TaskCubit` (`..watchTasks(DateTime.now())`) and `HabitCubit` (no `loadHabits()`)
- `UnifiedTasksPage` provides yet another `TaskCubit` (no `watchTasks()`)
- **Rule**: `context.read<TaskCubit>()` in `MainPage` subtree always gets the MainPage instance, never the global one

### Critical BlocProvider shadowing trap:
```
app.dart GlobalTaskCubit (watchTasks active)
  └── MainPage LocalTaskCubit (watchTasks active, used by add sheet)
        └── UnifiedTasksPage LocalTaskCubit (no watchTasks — DISPLAYS NOTHING)
              └── UnifiedTasksView (reads UnifiedTasksPage's empty cubit)
```
`TimelineCubit` (provided by `MainPage`) watches Isar directly via `watchTasksByDate()` and is the correct display path for `UnifiedTasksView`.

## Dependency Injection

**GetIt + Injectable**.
- Annotate: `@injectable`, `@singleton`, `@lazySingleton`
- After annotation changes: `flutter pub run build_runner build --delete-conflicting-outputs`
- Entry: `configureDependencies()` in `core/di/injection.dart`
- Generated: `core/di/injection.config.dart` — never edit manually
- Access: global `getIt` instance

## Data Layer

### Local — Isar
- `@collection` on model classes; `@embedded` on nested objects
- Schema files `*.g.dart` generated by `isar_generator` — never edit manually
- Stream-based watch: `isar.collection<T>().watchLazy()` or `watchObjects()`
- UUID generation: `const Uuid().v4()` auto-applied in model constructors (most models)

### Remote — Supabase
- PostgreSQL via `supabase_flutter`
- Credentials in `.env`: `SUPABASE_URL`, `SUPABASE_ANON_KEY`
- Loaded via `flutter_dotenv` before runApp

### Sync
- `SyncService` pushes Isar changes to Supabase
- Triggered at startup by `SyncCubit` and manually
- Background sync via `workmanager`

## Navigation

- `MaterialApp.routes` with named routes in `app.dart`
- No GoRouter in production (`core/config/routes.dart` is an unused stub)
- Global navigator key: `DeepLinkService.navigatorKey`
- Cold-start notification payloads consumed in `AtharApp.initState`

## Localization

- Primary locale: `ar-SA` (Arabic); secondary: `en-US`
- ARB files: `lib/l10n/app_ar.arb`, `lib/l10n/app_en.arb`
- Generated: `lib/l10n/generated/app_localizations.dart` — run `flutter gen-l10n` after ARB edits
- Runtime switching: `LocaleCubit.setLocale(Locale?)` → `FlutterSecureStorage('preferred_locale')`
- `MaterialApp` has explicit `localeResolutionCallback`: ar→ar-SA, en→en-US, other→en-US
- `LocaleCubit` null key = system default (device language)

## Design System

- Token barrel: `import 'package:athar/core/design_system/tokens/tokens.dart'`
- Token files: `athar_colors.dart`, `athar_typography.dart`, `athar_spacing.dart`, `athar_radii.dart`, `athar_shadows.dart`, `athar_animations.dart`
- `ScreenUtilInit` design size: 375×812
- Font: **Cairo** (Arabic-first; all weights)
- Atomic hierarchy: tokens → atoms → molecules → organisms → templates

## Error Handling

- Use cases: `dartz` `Either<Failure, T>`
- `core/error/failures.dart` is a stub; `Failure` subclasses defined inline per feature
- Cubits emit `*Error` states; pages/listeners show `SnackBar` via `BlocListener`

## Key Invariants

- `WidgetKeys` constants in `widget_data_service.dart` must never be renamed (breaks installed widgets)
- App Group ID `group.com.iappsnet.athar` must never change
- iOS minimum deployment target: 17.0 (required for AppIntentConfiguration)
- Never edit `*.g.dart` generated files
- `configureDependencies()` must be called before `runApp()`
